HARDWARE ARCHITECTURE & FINITE STATE MACHINE (FSM) SPECIFICATION

Galagoose: Space Shooter FPGA Edition

Target Platform: Digilent Nexys A7-100T (Xilinx Artix-7 XC7A100T-1CSG324C)  |  Clock Domain: 25 MHz VGA Pixel Clock  |  Tick Rate: 60 Hz VSync Pulse

เอกสารนี้ระบุรายละเอียดโครงสร้างและแผนผัง Finite State Machine (FSM) ทั้งหมดที่ควบคุมกลไกการทำงานของเกม Galagoose บนชิป FPGA ตั้งแต่ FSM ระดับบนสุด (Top-level Game Flow) ไปจนถึง Sub-FSM ของแต่ละฟีเจอร์สำคัญ เช่น การพัฒนาร่างห่าน 3 ระดับ, สกิลบาเรียเสียงสะท้อนกระสุน, พฤติกรรมการบินของเอเลี่ยน, เฟสการต่อสู้ของบอส AJV, ระบบรับประกันไอเทมดรอป, และไปป์ไลน์ประมวลผลสัญญาณเสียงไมโครโฟนดิจิทัล (PDM)

1. Master Game State Machine (FSM หลักควบคุมสถานะเกม)

FSM หลักควบคุมวงจรชีวิตของเกม (Game Lifecycle) ตั้งแต่การเปิดเครื่อง เลือกโหมด เล่นเกม และจบเกม สถานะถูกเก็บอยู่ในรีจิสเตอร์ game_state [2:0] ภายในโมดูล game_engine.sv

Diagram 1.1: Master Game State Transition Diagram
State Register รหัส State เงื่อนไขการทำงานในสถานะ เงื่อนไขการเปลี่ยนสถานะ (Next State Logic)
GS_TITLE 3'd0 หน้าจอเริ่มต้น แสดงชื่อเกม ปรับระดับความยาก (SW[3] หรือลูกศร) any_start_pulse $ ightarrow$ GS_WAVE_INTRO (ตั้ง wave=1, intro_timer=75)
GS_WAVE_INTRO 3'd1 แสดงข้อความ "WAVE X" นาน 75 เฟรม (1.25s), ศัตรูบินเข้าแถว intro_timer == 0 $ ightarrow$ GS_PLAY
GS_PLAY 3'd2 ประมวลผลเกมเต็มรูปแบบผ่าน 14 Sub-FSM Phases • player_lives == 0 || sw_giveup $ ightarrow$ GS_GAMEOVER
• wave_num == 4 && boss_hp == 0 $ ightarrow$ GS_VICTORY
• wave_num < 4 && en_active == 0 $ ightarrow$ GS_WAVE_INTRO (wave++)
• sw_pause == 1 $ ightarrow$ GS_PAUSED
GS_PAUSED 3'd3 หยุดนับเฟรมเกม แช่แข็งพิกัด แสดงตัวอักษร PAUSED sw_pause == 0 $ ightarrow$ GS_PLAY
GS_VICTORY 3'd4 แสดงคำว่า VICTORY! YOU WIN, เล่นเพลงชัยชนะ any_start_pulse $ ightarrow$ GS_TITLE (เริ่มรอบใหม่)
GS_GAMEOVER 3'd5 แสดงคำว่า GAME OVER, อัปเดต High Score any_start_pulse $ ightarrow$ GS_TITLE

8. Hardware Multi-Phase Execution Pipeline (Sub-FSM ในระดับ Clock Cycle)

เพื่อลดความยาวของ Critical Path และหลีกเลี่ยง Timing Violation ใน FPGA ชิป Artix-7, โมดูล game_engine.sv ไม่ได้ประมวลผลทุกอย่างในรอบสัญญาณนาฬิกาเดียว แต่ใช้ Sub-FSM Time-Multiplexing 14 Phases:

Phase ชื่อ Phase หน้าที่และการคำนวณในระดับสัญญาณนาฬิกา
4'd0 PH_IDLE รอสัญญาณ game_tick (พัลส์ 60 Hz 1 รอบสัญญาณนาฬิกาเมื่อสิ้นสุดเฟรมภาพ VGA)
4'd1 PH_PLAYER อัปเดตตำแหน่งห่าน (ปุ่มกด/เอียงบอร์ด), นับถอยหลังร่างห่าน, ตรวจจับเสียงกางบาเรีย
4'd2 PH_SPAWN_PB ตรวจสอบการกดปุ่มยิง/Autofire สปอว์นกระสุนตามฟอร์มห่าน (1 นัด, 3 นัด, หรือ 5 นัด)
4'd3 PH_UPD_PB คำนวณพิกัด $X, Y$ กระสุนผู้เล่นทั้ง 32 นัด และปิดการทำงานเมื่อหลุดขอบจอ
4'd4 PH_COL_PB ตรวจจับการชนระหว่างกระสุนผู้เล่นกับมินเนียนทั้ง 16 ตัว และบอส AJV แบบ Round-Robin
4'd5 PH_UPD_EN อัปเดตฟิสิกส์การบินของเอเลี่ยนลูกกระจ๊อกตาม FSM โหมดบิน (Enter, Form, Dive, Return)
4'd6 PH_UPD_BOSS อัปเดตการเคลื่อนที่บอส AJV, การสลับทิศทาง, การเข้าสู่เฟสคลั่งตาแดงเมื่อเลือด $\le 50\%$
4'd7 PH_UPD_EB อัปเดตกระสุนศัตรู ตรวจจับการชนกับตัวห่าน หรือการสะท้อนมุมเมื่อชนบาเรียเสียง
4'd8 PH_UPD_ORB อัปเดตการตกของไอเทม Orb และการชนเก็บไอเทมเพื่อแปลงร่างห่าน
4'd9 PH_UPD_EXP นับถอยหลังเฟรมแอนิเมชันลูกไฟระเบิด 8 ช่อง
4'd10 PH_WAVE_CHK ตรวจสอบเงื่อนไขผ่านด่าน (ลูกกระจ๊อกหมด / บอสตาย) หรือเงื่อนไขแพ้ (เลือดหมด)
4'd11 PH_INIT_WAVE เซ็ตอัปพิกัดเริ่มต้น ประเภทศัตรู และเลือดเริ่มต้นสำหรับเวฟถัดไป
4'd12 PH_HUD_X อัปเดตข้อมูล Text Character Buffer ลง BRAM เพื่อแสดงผล HUD บนจอ VGA
4'd13 PH_BOSS_FIRE คำนวณและสปอว์นรูปแบบกระสุนของบอส (Radial Salvo หรือ Spinning Vortex Barrage)
