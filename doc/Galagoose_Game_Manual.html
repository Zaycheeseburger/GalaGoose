1. กฎการเล่นและเงื่อนไขสถานะเกม (Game Rules & State Conditions)

GALAGOOSE คือเกมยานยิงอวกาศสไตล์ Galaga Arcade ที่ออกแบบและประมวลผลด้วยลอจิกฮาร์ดแวร์ SystemVerilog/Verilog 100% บน FPGA Artix-7 โดยปราศจากการใช้ CPU หรือระบบปฏิบัติการซอฟต์แวร์ ผู้เล่นจะบังคับยาน "ห่านอวกาศ" ต่อกรกับกองทัพเอเลี่ยนและเผชิญหน้ากับ Last Boss ในด่านสุดท้าย

กฎพื้นฐานการเล่น (Core Rules)

  • พลังชีวิตเริ่มต้น (Player Lives): เริ่มเกมด้วย 3 ชีวิต (แสดงเป็นไอคอนหัวใจบน HUD ด้านบนขวา) เมื่อถูกกระสุนหรือชนศัตรู จะเสีย 1 ชีวิตและเข้าสู่สถานะอมตะชั่วขณะ (Invulnerability) กะพริบ 1.5 วินาที
  • ขอบเขตสนามรบ (Playfield Boundaries): ยานห่านเคลื่อนที่ได้อย่างอิสระ 4 ทิศทางภายในพิกัด X: 16–592 และ Y: 72–440 (ความละเอียดจอรวม 640x480)
  • การทำคะแนน (Scoring):
    • ลูกกระจ๊อก Wave 1 = +100 คะแนน / Wave 2 = +150 / Wave 3 = +200
    • กำจัด Last Boss (Wave 4) = +2,000 คะแนน
    • เก็บลูกแก้ววิวัฒนาการ = +50 คะแนน / เก็บหัวใจฟื้นเลือด = +500 คะแนน
    • คะแนนสูงสุด (High Score) บันทึกแบบ Decimal BCD และคงอยู่ตลอดการเปิดเครื่อง

เครื่องสถานะหลักของเกม (FSM Game States)

Game State เงื่อนไขและพฤติกรรมของระบบ
GS_TITLE (0) หน้าจอเริ่มเกม แสดงโลโก้ Galagoose พร้อมเพลงเปิดตัว เลือกโหมด Normal/Hard ได้
GS_WAVE_INTRO (1) แอนิเมชันเปิดด่าน แสดงข้อความ "WAVE X" หน่วงเวลา 2.5 วินาทีให้เตรียมตัว
GS_PLAY (2) สถานะเล่นเกมจริง ทำการอัปเดตตำแหน่ง ตรวจจับการชน ยิงกระสุน และไอเทม
GS_PAUSED (3) หยุดเกมชั่วคราวเมื่อสับ SW[15]=ON ยานและกระสุนทั้งหมดจะหยุดนิ่ง
GS_VICTORY (4) พิชิต Last Boss ใน Wave 4 สำเร็จ แสดงข้อความ VICTORY พร้อมเพลงฉลองชัยชนะ
GS_GAMEOVER (5) ชีวิตหมดเหลือ 0 หรือสับสวิตช์ยอมแพ้ SW[14]=ON
2. ระบบวิวัฒนาการห่าน 3 ขั้น (Goose Evolution Mechanics)
ร่าง 1: ห่านขาว (White Goose)
[Form 0 - ร่างเริ่มต้น]

ยิงกระสุนปืนคู่ธรรมดา 1 ชุด/ครั้ง
Cooldown: 12 เฟรม (~5 นัด/วินาที)
เป็นร่างถาวร ไม่จำกัดเวลา

ร่าง 2: ห่านฟ้า (Blue Goose)
[Form 1 - หอกพลาสมาคู่]

ยิงหอกพลาสมาคู่สีฟ้า ดาเมจสูงขึ้น
Cooldown: 8 เฟรม (~7.5 นัด/วินาที)
จำกัดเวลา: 9.0 วินาที

ร่าง 3: ห่านรุ้ง (Rainbow Goose)
[Form 2 - อัลติเมต 8 ทิศทาง]

ยิงกระจายรอบทิศ 8 แฉก 180° ด้านหน้า
Cooldown: 5 เฟรม (~12 นัด/วินาที)
จำกัดเวลา: 9.0 วินาที

กลไกตัวนับเวลาถอยหลัง 9 วินาที (Evolution Countdown): ขณะอยู่ในร่างห่านฟ้าหรือห่านรุ้ง บนแถบ HUD จะแสดงเวลานับถอยหลัง EVO TIME: 9S...1S หากหมดเวลาจะลดระดับลงสู่ร่างก่อนหน้า แต่หากเก็บลูกแก้วพัฒนาขั้นถัดไปได้ทัน ตัวจับเวลาจะถูกรีเซ็ตเต็ม 9 วินาทีใหม่ทันที
3. สกิลบาเรียพลังงานเสียงคุ้มกัน (Voice-Activated Defensive Shield)

ฟังก์ชันพิเศษที่ออกแบบสำหรับใช้รับมือกับ Last Boss (Wave 4) โดยเฉพาะ เพื่อช่วยให้ผู้เล่นสามารถเอาชีวิตรอดจากห่ากระสุนสุดโหด:

การทำงานของระบบบาเรียป้องกันตัวห่าน (Pure Defensive Barrier)

  • เงื่อนไขการใช้งาน: ใช้ได้เฉพาะในด่าน Last Boss (Wave 4) ขณะที่บอส AJV กำลังมีชีวิตอยู่ในฉากเท่านั้น
  • วิธีการสั่งใช้งาน: ตะโกนหรือออกเสียงดังใส่ ไมโครโฟนออนบอร์ด (ADMP421) ให้ระดับพลังงานเสียงพุ่งแตะหรือข้ามขีดมาร์กเกอร์สีแดง
  • ระยะเวลาทำงานของบาเรีย: กางวงแหวนพลังงานคุ้มกันรอบตัวห่านเป็นเวลา 3.0 วินาทีเต็ม (180 เฟรม)
  • คุณสมบัติการป้องกัน 100%:
    • ดูดซับและทำลายกระสุนของศัตรู/บอสทั้งหมดที่พุ่งเข้าใกล้ในรัศมี 32 พิกเซล พร้อมเสียงสะท้อนปิ๊ง (Deflection SFX)
    • ป้องกันดาเมจจากการชนตัวศัตรู และป้องกันการชนตัวบอส (ไม่เสียพลังชีวิตเลยขณะบาเรียทำงาน)
    • ไม่ทำดาเมจใส่บอส: กระสุนที่ดูดซับจะไม่สะท้อนไปสร้างความเสียหายแก่บอส ทำให้เกมคงความท้าทายในการโจมตีด้วยตนเอง
  • ระบบคูลดาวน์ใหม่ (Sequential Post-Barrier Cooldown):
    • ตัวนับคูลดาวน์จะเริ่มทำงาน หลังจากบาเรีย 3 วินาทีหมดอายุลงแล้วเท่านั้น
    • ระยะเวลาคูลดาวน์: 8.0 วินาทีเต็ม (480 เฟรม) รวมรอบการใช้งานทั้งหมด $3.0 + 8.0 = 11.0$ วินาที
    • ระหว่างคูลดาวน์ ผู้เล่นจะไม่สามารถเปิดบาเรียซ้ำได้ และต้องหลบหลีกการโจมตีจนกว่าหลอดจะรีชาร์จเต็ม 100%

4. การเชื่อมต่อและควบคุมด้วยส่วนประกอบบนบอร์ด Nexys A7 (Hardware I/O Specification)

ปุ่มกด (Push Buttons) & การควบคุม

ปุ่ม / เซนเซอร์ การทำงานในระบบเกม
BTNC (Center) ยิงกระสุน (Fire) / ยืนยันเริ่มเกมในหน้าเมนู Title
BTNU (Up) บังคับยานห่านบินขึ้นด้านบน ($Y-$)
BTND (Down) บังคับยานห่านบินลงด้านล่าง ($Y+$)
BTNL / BTNR บินไปทางซ้าย ($X-$) / บินไปทางขวา ($X+$) / เลื่อนเลือกเมนู
CPU_RESETN ปุ่มสีแดง: ฮาร์ดแวร์รีเซ็ตระบบเกมทั้งหมดกลับสู่เริ่มต้น
ADXL362 Tilt เซนเซอร์เอียงบอร์ด 3 แกน แปลงมุมเอียงเป็นความเร็วการบิน
PS/2 Keyboard รองรับคีย์บอร์ด WASD หรือลูกศร, Space ยิง

การปรับแต่งด้วยสวิตช์สไลด์ (Slide Switches SW[15:0])

สวิตช์ ฟังก์ชันการทำงาน
SW[0] Audio Mute: ON = ปิดเสียงลำโพงทั้งหมดเงียบสนิท
SW[1] Autofire: ON = ยิงกระสุนรัวอัตโนมัติ ไม่ต้องกดย้ำ
SW[2] Tilt Control: ON = เปิดระบบบังคับด้วยการเอียงบอร์ด
SW[3] Hard Mode Override: ON = บังคับโหมด Hard ทันที
SW[4] Debug Mode: ON = แสดง Hitbox สี่เหลี่ยม และโค้ดคีย์บอร์ด
SW[5] Keyboard Priority: ON = ตัดปุ่มบนบอร์ด ใช้คีย์บอร์ดล้วน
SW[6] Key Swap: สลับปุ่มควบคุมระหว่างลูกศรกับ WASD
SW[13:12] Mic Sensitivity: ปรับระดับความไวไมค์ Voice Barrier
00: Normal (85) / 01: Sensitive (65)
10: Louder (105) / 11: Shouting (130)
SW[14] Give Up / Surrender: ON = ยอมแพ้และสิ้นสุดเกมทันที
SW[15] Pause Game: ON = หยุดเกมชั่วคราว

การแสดงผลอุปกรณ์เอาต์พุตบนบอร์ด Nexys A7

  • 16-LED Bar (LED[15:0]): ใน Wave 1–3 แสดงไฟติดตามตำแหน่งศัตรู 16 ตัว / ใน Wave 4 แปลงเป็น Boss HP Bar 16 หลอด ดับลงตามเลือดบอส
  • RGB LEDs (LED16, LED17): แสดงสีตามร่างวิวัฒนาการห่าน (ขาว/ฟ้า/รุ้ง) และกะพริบเตือนสีแดงเมื่อได้รับความเสียหาย
  • 7-Segment Display (8 หลัก): แสดงคะแนนสะสม 6 หลัก (Decimal BCD) หรือแสดงรหัส Scan Code ในโหมด Debug
  • VGA Video Port (RGB444): ส่งสัญญาณ 640x480 @ 60Hz 12-bit พร้อมระบบสั่นจอ (Screen Shake) และ Parallax Starfield 3 ชั้น
  • Audio PWM: สังเคราะห์เสียง Chiptune ยุค 8-bit ขับเสียงดนตรีประกอบฉากและเสียงเอฟเฟกต์ SFX ผ่านช่องต่อแจ็ค 3.5 มม.
5. กฎและจังหวะเวลาการปล่อยไอเทม (Item Drop Rules & Timing)

ก. กฎในด่านปกติ (Wave 1 – 3)

  • ดรอปตามลำดับขั้นบันไดห่านเคร่งครัด:
    • ห่านขาว (Form 0) $ ightarrow$ ดรอป ลูกแก้วฟ้า (Type 0)
    • ห่านฟ้า (Form 1) $ ightarrow$ ดรอป ลูกแก้วรุ้ง (Type 1)
    • ห่านรุ้ง (Form 2) $ ightarrow$ ดรอป หัวใจฟื้นเลือด (Type 2)
  • การันตีการดรอปต้นเกม:
    • ศัตรูที่ถูกยิงตกตัวที่ 2 ใน Wave 1 ปล่อยลูกแก้วฟ้าแน่นอน
    • ศัตรูที่ถูกยิงตกตัวที่ 2 ใน Wave 2 ปล่อยลูกแก้วรุ้งแน่นอน

ข. กฎในด่าน Last Boss (Wave 4)

  • ใช้กฎขั้นบันไดเดียวกัน (ไม่มีการข้ามขั้น): ห่านขาวต้องผ่านห่านฟ้าก่อน จึงจะมีสิทธิ์พัฒนากลายเป็นห่านรุ้งได้
  • การันตีปล่อยลูกแก้วรุ้งทันใน 9 วินาที: เมื่อเก็บลูกแก้วฟ้ากลายร่าง บอสจะรีเซ็ตเวลารอปล่อยลูกแก้วรุ้งเหลือเพียง 2.5 - 3.0 วินาที ทำให้ผู้เล่นมีโอกาสพัฒนาร่างสู่ห่านรุ้งได้อย่างแน่นอนก่อนหมดเวลา
  • ความถี่การดรอปในด่านบอส:
    • ห่านขาว: ปล่อยลูกแก้วฟ้าทุก 4.0 วินาที
    • ห่านรุ้ง: ปล่อยหัวใจฟื้นเลือดทุก 5.0 วินาที
    • หากพลาดการเก็บลูกแก้วรุ้ง บอสจะดรอปซ้ำทุก 3.0 วินาที
  • Milestone Drops: ปล่อยหัวใจฉุกเฉินทันทีเมื่อเลือดบอสลดลงแตะ 50% และ 25%
6. ตารางเปรียบเทียบเชิงลึก: โหมด Normal vs Hard

ผู้เล่นสามารถเลือกโหมดความยากได้ที่หน้า Title Screen หรือสับสวิตช์ SW[3] = ON เพื่อบังคับเป็นโหมด Hard:

พารามิเตอร์ของระบบ โหมดปกติ (NORMAL MODE) โหมดท้าทาย (HARD MODE) ความแตกต่างและผลกระทบต่อผู้เล่น
Boss Max HP (พลังชีวิตบอส) 90 หน่วย 120 หน่วย (+33%) การต่อสู้ยาวนานขึ้น ต้องรักษาพลังห่านรุ้งเพื่อทำดาเมจสูงสุด
ความเร็วการเคลื่อนที่ของบอส 3 พิกเซล / เฟรม 4 พิกเซล / เฟรม (+33%) บอสบินโฉบซ้ายขวารวดเร็วขึ้นอย่างชัดเจน เล็งยิงได้ยากขึ้น
การหักเลี้ยวหลอกล่อ (Feint Weave) สุ่มเลี้ยวเมื่อ LFSR == 9'h155 (ความถี่ต่ำ) สุ่มเลี้ยวเมื่อ LFSR == 8'hA5 (ถี่ขึ้น 2 เท่า) ทิศทางของบอสคาดเดายาก มีจังหวะเปลี่ยนทิศกะทันหันบ่อยครั้ง
ความถี่กระสุนบอส Phase 1 (ajv) หน่วงเวลา 60 เฟรม (1.00 วินาที/ชุด) หน่วงเวลา 45 เฟรม (0.75 วินาที/ชุด) ในเฟสแรก กระสุนบอสสาดถี่ขึ้น 25%
ความถี่กระสุนบอส Phase 2 (ajv2) หน่วงเวลา 18 เฟรม (0.30 วินาที/ชุด) หน่วงเวลา 14 เฟรม (0.23 วินาที/ชุด) เข้าสู่สภาวะห่ากระสุน (Bullet Hell) รัวเร็วและหนาแน่นสูงสุด

ก. พฤติกรรมของลูกกระจ๊อก (Minion FSM Patterns)

  • Mode 0 (Entry): บินโค้งเข้าสู่หน้าจอจากด้านบนเพื่อเข้าประจำตำแหน่ง
  • Mode 1 (Formation Sway): จัดขบวนปีกนกด้านบน บินส่ายไปมาซ้ายขวาแบบกลุ่ม พร้อมยิงกระสุนเล็งต่ำเป็นระยะ
  • Mode 2 (Dive Bombing): บินแยกตัวออกจากขบวน โฉบดิ่งลงมาหายานห่านด้วยความเร็วสูงพร้อมยิงกระสุนดักทาง
  • Mode 3 (Return): เมื่อบินทะลุขอบล่าง จะวนโค้งกลับขึ้นไปจัดขบวนใหม่ที่ด้านบน

ข. Last Boss (AJV) 2 เฟสการต่อสู้

  • Phase 1: ร่างอาจารย์เจษฎาปกติ (HP > 50%):
    • ใช้รูปสไปรต์ ajv หน้าปกติ ขอบคมชัดเต็มรูป
    • บินเคลื่อนไหวแบบ Sinusoidal Sway นุ่มนวล ยิงกระสุนเล็งเป้าเดี่ยวและคู่
  • Phase 2: ร่างคลั่ง Enraged AJV2 (HP $\le$ 50%):
    • สลับใช้รูปสไปรต์ ajv2 ตาเลเซอร์สีแดง ดุดัน คมชัดไม่มีพื้นหลัง
    • เคลื่อนที่โฉบลึกและรวดเร็ว สุ่มเลี้ยวหักมุมหลอกล่อ (Feint)
    • ยิงกระสุนเกลียวกระจายรอบทิศ (Radial Salvos 7–8 ทิศทาง) บีบให้ผู้เล่นต้องใช้ "บาเรียเสียง" ในจังหวะสำคัญเพื่อเอาชีวิตรอด
